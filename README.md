# Northline: Jacket Checkout Redesign

CSE 463 Final Project, Milestone 1 · Nandini Prashant Bahirgonde

**Live prototype:** https://nandinibahirgonde.github.io/cse463-Milestone1/

An HTML/CSS/JavaScript prototype that redesigns the jacket checkout flow on oldnavy.com. "Northline" is a made-up store; nothing is sold or charged.

**How to use:** Open the link in a desktop browser. Use "Reset prototype" (top right) to start over. Test card: `4242 4242 4242 4242`.

This is the pre-test version for Milestone 1.
